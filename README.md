# Expojud 2026

Página estática publicada pelo GitHub Pages a partir da pasta `docs/` da branch `main`.

Endereço temporário: https://bonniekdsg.github.io/expojud26/

## Domínio definitivo

O domínio planejado é `expojud26.mpac.mp.br`. Enquanto o DNS do MPAC não apontar esse nome para o GitHub Pages, mantenha o campo **Custom domain** vazio em **Settings → Pages** para que o endereço temporário funcione.

Quando a equipe responsável pelo DNS puder configurá-lo:

1. Crie o registro `CNAME` de `expojud26.mpac.mp.br` apontando para `bonniekdsg.github.io`.
2. Em **Settings → Pages**, informe `expojud26.mpac.mp.br` no campo **Custom domain**. O GitHub criará `docs/CNAME` com esse nome.
3. Aguarde a verificação do DNS e habilite **Enforce HTTPS** quando o certificado estiver disponível.

O endereço `expojud2026.mpac.mp.br` apareceu em uma configuração antiga, mas o nome planejado para este projeto é `expojud26.mpac.mp.br`.
